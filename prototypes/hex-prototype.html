Standalone prototype — does not touch trace.html or trace-core.js. The script is split into topology / generator / puzzle / render / input layers; the topology layer (cube coords, 6-neighbour adjacency, hex geometry) is the seam Core would gain as a topol spec dimension. Every rolled value is in the URL (?topol=hex&side=6&pts=N&seed=…) so any board is shareable.
